# Рабочее место врача «Синкли»

Врач ведёт пациента до, во время и после приёма. Главная ценность — сохранённая целостная история, ясный следующий шаг и достоверные основания решения. Язык русский, спокойный и конкретный.

Существующий визуальный язык: Onest, молочные поверхности, тёмно-зелёный текст и зелёный акцент. Сохраняем его. Плотность средняя/высокая: таблицы и строки для сравнения, крупные поля для записи. Рабочий день и очередь событий, пациент и активный приём — основные контексты.

Авторский приём: непрерывная вертикальная линия истории связывает визиты, измерения и изменения плана; справа у записи видны дата и основание. Маленький индикатор сохранения всегда рядом с рабочим контекстом.

CRAFT_LEVEL 8, MOTION_INTENSITY 4, VISUAL_DENSITY 7, DESIGN_VARIANCE 3 — выбор исполнителя по задаче. CSS-переходы 120/200/280 мс для фокуса, переключений и диалога; таблицы не анимируются при каждом обновлении. Reduced motion отключает перемещение. Уважать клавиатуру, увеличение текста, ширину 360 px.

Навигация: рабочий день / пациенты / календарь / события / источники. В карте: обзор / приёмы / динамика / план / дневник / сообщения / документы. Приём: контекст / оценка / заключение и план / подтверждение. Черновики сохраняются; закрытый приём доступен для чтения и отдельного дополнения.

Медицинская интерпретация принадлежит врачу. Непроверенный источник имеет видимый статус. Не называть событие обработанным по факту открытия. Не обещать доставку человеку без подтверждения системы.
