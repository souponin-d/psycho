# Токены рабочего места врача

Основа: `packages/ui-web/src/styles/tokens.css`; расширение только внутри `.doctor-workspace`, без изменения других приложений.

- Шрифт Onest, 14 px основной текст, 13 px метаданные, 16 px поля на телефоне, 24–32 px заголовок контекста. Числа tabular-nums.
- Поверхности: `#fafbf7` страница, `#ffffff` карта, `#f1f4ee` боковая панель; текст `#1c2924`, вторичный `#56645c`; граница `#dfe5dc`.
- Акцент `#355e4a`, мягкий фон `#e7efdf`. Дополнительные цвета только для смыслов ошибки/внимания и различимых рядов данных.
- Шаги 4/8/12/16/24/32 px; поля 8 px, панели 14 px, диалог 18 px. Тени мягкие двухслойные, без тяжёлых контуров.
- Длительности 120/200/280 ms, easing cubic-bezier(.22,1,.36,1). Выход 150 ms, отсутствие анимации таблиц и метрик при загрузке.
- Минимальная интерактивная область 40 px на desktop, 44 px на touch; видимый фокус 3 px и подчеркивание у текстовых ссылок.
