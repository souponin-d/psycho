## Шаблон решения

```markdown
# NNNN. Название решения

Дата:
Статус: предложено / принято / заменено.

## Контекст

Какую задачу решаем и какие ограничения известны?

## Варианты

Какие подходы рассматривались и какие у них существенные различия?

## Решение

Что выбрали, кто участвовал в обсуждении и почему?

## Последствия

Что получаем, какие ограничения принимаем и когда пересматриваем выбор?
```
