## Результат

На первом экране сайта доступны ссылки «Демо врача» и «Демо администратора». «Открыть демо» в шапке и ссылка в блоке экосистемы ведут к этим входам. При ширине 360 px обе ссылки доступны непосредственно на первом экране; пункт «Демо» есть и в мобильном меню. Старый учебный сценарий сохранён отдельной кнопкой.

Оба приложения открываются на том же origin в demo/doctor/ и demo/admin/. В верхней части каждого демо есть «На сайт Синкли». Навигация, прямые адреса с hash и примеры остаются рабочими. В общей версии показана подпись «Демо · синтетические данные»; отдельные приложения сохраняют режим разработки.

Vite собирает три HTML-входа из site/vite.config.ts. Файлы в site/demo/ подключают существующие apps/web-doctor/src/main.tsx и apps/web-admin/src/main.tsx через короткие входные модули. Логика, стили и данные приложений не копируются в лендинг. Сборка использует относительные ссылки; один корневой dist включает все три страницы и общие assets. Отдельные команды запуска и сборки приложений сохранены, новых зависимостей нет.

## Воспроизведение

Из корня клона после npm ci --ignore-scripts:

```sh
npm run dev -- --port 8771
```

Либо production-сборка:

```sh
npm run build
npm run preview -- --port 8772
```

В браузере открыть корневой адрес из вывода команды, перейти в демо врача, затем «На сайт Синкли», в демо администратора и обратно. Для публикации отдавать весь корневой dist, включая demo/ и assets/. Сервер должен поддерживать index.html вложенных каталогов. Отдельные origins/порты приложений и API не нужны.

## Границы

Выполнено подключение уже существующих приложений к сайту. Заготовки задач #5–#7 сохраняются. Авторизация, клинические функции, сервер, БД, синхронизация и мобильное приложение не добавляются. Старый сценарий лендинга не становится источником данных приложений. Изменения не требуют миграции; откат выполняется отдельным revert через PR.

Реальная настройка production-хостинга и браузерный zoom этим проходом не проверялись. Статическая сборка и переходы проверены через локальный preview; тест относительных ресурсов не выдаётся за реальный сервер с префиксом /project/.
