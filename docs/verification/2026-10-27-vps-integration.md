> **Статус документа:** Историческое свидетельство: результаты и ограничения относятся к указанной ниже дате и версии. Они не являются текущим статусом всего продукта. [Текущее состояние](../status.md).

По поручению владельца после слияния [PR №53](https://github.com/souponin-d/psycho/pull/53) обновлены API и полная веб-статика на VPS. Исходники: `main`, `90ee18d584d0fc7fa864d206fe01fa5640810cb7`. Релиз: `20261027-integration-90ee18d`.

[Кабинет врача](https://176.32.37.10/doctor/) и [health API](https://176.32.37.10/api/health) доступны по HTTPS. Код доступа, логин/пароль, БД и ключи сохранены; новые реквизиты не выдавались. APK не загружался на VPS. Демо-режимы сохранены.

## Подготовка и проверки

- Все GitHub checks PR №53 прошли после разрешения конфликтов, включая PostgreSQL API и проверки мобильного приложения, веба, fixtures и репозитория на Windows/Ubuntu.
- `dotnet publish apps/doctor-api/Doctor.Api.csproj -c Release -r linux-x64 --self-contained false` — Linux API собран; `npm run build` — полная веб-статика собрана.
- `python scripts/test_vps_update.py` — 8 проверок механизма обновления прошли.
- SHA-256 пакета: `4d7f0369495c93cfcbf2edcfcbe5716266b79f3b5feddf4918650578fafe56a3`. Проверены хэши 21 файла API и 32 файлов веба, отсутствие APK и значений приватных реквизитов.
- Перед переключением создана зашифрованная копия БД, env, PFX и ключей. Расшифровка и восстановление в отдельную временную БД прошли; число карт и сообщений совпало. Временная БД удалена. Копия хранится на VPS; её скачивание на компьютер заблокировано автоматической проверкой разрешений и не выполнено.
- После переключения health вернул `ready`, `postgresql` и ожидаемый release ID. HTML `/`, `/doctor/`, `/demo/admin/` совпал с новой сборкой.
- `scripts/verify-vps-hackathon.py` через HTTPS проверил вход врача, вход по коду и отказ неверному коду, привязку карты, роли, secure cookies, CSRF, повтор сообщения без дублей и ответ врача.
- Дополнительная проверка реального `createPatientChannel` на VPS: декодирование назначений приёма/опросов/самоотчётов, исходные поля самоотчёта у врача, повтор без дублей, восстановление после нового входа и отказ несуществующему расписанию. В тестовой карте оставлены явно синтетические технические сообщение и самоотчёт.
- Установленный release APK 0.4.4, versionCode 8, на Android-эмуляторе API 37 вошёл по коду в обновлённый VPS и показал ответ врача на экране «Связь с врачом». Масштаб шрифта 1.0. APK не пересобирался: код приложения после поставки не изменялся.

Все сценарии назначений, отметок и PHQ-9/GAD-7 прошли локальную интеграционную проверку, описанную в [основном отчёте](2026-10-27-patient-doctor-integration.md). Публичная проверка не создавала новые назначения препаратов и не проходила выданные пациенту опросы; её нельзя считать повторением всего локального набора. Клиническое утверждение не получено. Ограничения серверных напоминаний и переноса игровой истории сохраняются.

## Расположение и откат

API: `/opt/syncli/releases/20261027-integration-90ee18d/api`; веб: `/srv/syncli/releases/20261027-integration-90ee18d`. Caddy, настройки доступа, ключи и рабочая БД не переустанавливались. Пакет и метаданные проверки находятся в `/root/syncli-layero44/20261027-integration-90ee18d`; резервная копия — `/root/syncli-backups/20261027-integration-90ee18d.tar.enc`.

Для отката API/env от root выполнить `python3 /root/syncli-layero44/20261027-integration-90ee18d/update-api.py --rollback 20261027-integration-90ee18d --backup-password-file /root/syncli-layero44/20261026-layero44-19e10c2/backup-password`. Скрипт возвращает API `/opt/syncli/releases/20261026-layero44-19e10c2` и перезапускает службу, сохраняя текущую БД и ключи. Для веба атомарно вернуть `/srv/syncli/current` на `/srv/syncli/releases/20261026-hackathon-v1`; затем проверить HTTPS, входы и двусторонние сообщения. Старый API не поддерживает новые команды 0.4.4, поэтому при откате требуется согласовать версию клиента. Секреты в команды и журналы не выводить.
