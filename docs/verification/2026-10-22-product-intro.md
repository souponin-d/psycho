# Проверка блока знакомства с продуктом — 22 октября 2026

Описание и две кнопки демо расположены слева, макеты компьютера и телефона — справа. На узком экране элементы следуют друг за другом. Кнопка «Учебный сценарий» удалена. Полное содержимое её окна перенесено непосредственно в раздел «02 / Общая среда», с сохранением переключения ролей, выбора сценария, общей истории и сброса. Другие ссылки на этот пример ведут к встроенному блоку.

## Проверки

- `npm run check` — успешно: форматирование, ссылки Markdown, синтаксис JavaScript и общая сборка.
- `npm run check:web` — успешно: 42 теста в 9 файлах, TypeScript и сборки веб-приложений.
- `git diff --check` — успешно.
- Новый тест `scripts/site-inline-demo.test.ts` проверяет самоотчёт пациента, получение врачом, подтверждение, историю клиники, сброс и выбор сценария. До реализации тест падал из-за отсутствия встроенного блока; после реализации проходит.
- В браузере проверены размеры 1440, 1280, 390 и 320 пикселей; горизонтального переполнения нет.
- Проверены переключение ролей стрелкой с клавиатуры, отправка самоотчёта, подтверждение и сброс. Окно сведений о защите данных открывается и закрывается.
- Проверка кода агентом не выявила блокирующих замечаний. Она не заменяет независимое одобрение участника команды.

Проверка относится к маркетинговому демо с вымышленными данными и не подтверждает клинический процесс. Изменения подготовлены локально, без публикации.
