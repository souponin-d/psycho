# Ежедневная работа врача: шесть правок интерфейса

27 октября 2026 года. Реализация в ветке `codex/doctor-daily-workflow-copy`, обновлённой до `origin/main` (`b60d708`). По поручению владельца изменения подготовлены для PR в `main`; VPS не обновлялся. Основание — [согласованный план](../superpowers/plans/2026-10-27-doctor-daily-copy.md).

## Результат

1. «Новая версия» заменена на «Изменить назначение»; история и создание новой записи при изменении сохранены.
2. «Смещение UTC, минут» заменено выбором «Часовой пояс». Новое расписание получает смещение устройства врача, существующее сохраняет прежнее. Передача `offsetMinutes` в API не изменилась. Формат остаётся фиксированным UTC-смещением, переходы летнего времени не добавлялись.
3. Убраны повторные пояснения об устройстве черновиков, авторе/времени сохранения и истории. Состояния сохранения, ошибки, клинические ограничения и подтверждения остались.
4. Снимок ГРЛС и регистрационные сведения раскрываются по запросу; статус регистрации виден сразу. Основания плана, методики шкал и сравнение версий перенесены в раскрытия. Технические ID убраны из названий действий и источников; код источника доступен в его сведениях. Варианты заданий названы по опроснику и сроку, идентификаторы в данных сохранены.
5. Ссылки на законы удалены из переписки. Сохранены статусы доставки, проверка согласия и краткое предупреждение для серверного канала.
6. Ошибки завершения стали ссылками. Ссылки открывают нужный шаг, прокручивают к полю и ставят фокус. Ошибки согласий открывают форму с нужным назначением документа. Переход из окна подтверждения закрывает его; автоматического завершения приёма нет.

API, БД, права, клинические пороги и серверные проверки не изменены. Записи пациентов и аудит не переписывались.

## Проверки

- Новые регрессионные тесты: три перехода к полям, два назначения согласий, переход из окна подтверждения, автоподстановка часового пояса и сохранение прежнего смещения. Проверяется отсутствие автоматической команды завершения.
- В браузере на `127.0.0.1:8772` проверены новый текст действия, раскрытия оснований, отсутствие законов в переписке и переход к полю рисков. Фокус оказался в соответствующем `textarea`, URL приёма не изменился.
- Форма расписания отдельно проверена на копии синтетической карты: автоматически выбран `UTC+03:00`, передаваемое значение — `180`. Временная страница компонента удалена после проверки, данные не отправлялись на VPS.
- Отдельная проверка diff не выявила блокирующих замечаний; она не является человеческим approve.

При полном прогоне обнаружен старый тест клинического контекста, который сравнивал оценку за 26 октября с текущей датой запуска. После смены суток он закономерно падал. Тест закреплён на собственной дате: проверки изменения контекста и источника сохранены, клинический код не менялся.
