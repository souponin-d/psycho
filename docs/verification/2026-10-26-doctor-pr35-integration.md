# Интеграция PR #35 с актуальным кабинетом врача

Дата: 26 октября 2026 года. Задача: [#36](https://github.com/souponin-d/psycho/issues/36), [PR #35](https://github.com/souponin-d/psycho/pull/35).

Объединены исходный коммит PR `97b128b` и `main` `b23a507`. Разрешены конфликты в шести файлах. Сохранены принятый интерфейс врача, очередь внимания, общий контекст пациента, подготовительная проверка Авиандра и широкие диалоги. Перенесены новая модель контекста, статусы и выбор диагнозов. Общий контракт регенерирован штатной командой.

Сохранены поля лекарственного анамнеза, нежелательных явлений и приверженности. Диагнозы видны в итоге приёма. Психиатр явно меняет статус выбранного диагноза; сервер и локальный адаптер отвергают подтверждение без требуемой специальности. Клинические правила не активированы.

## Фактическая проверка

Общая проверка документации и сайта выполнялась в исходном Git-worktree; остальные проверки — в чистой копии на D:. Проверки выполнялись на Windows, Node.js 24.19.0, npm 11.17.0, .NET SDK 10.0.402 и отдельном PostgreSQL-стенде на порту 55445. Исходники для проверки скопированы из изолированного worktree на диск D: из-за нехватки места на C:. В чистой копии выполнена `npm ci --ignore-scripts`, lockfile не менялся.

| Проверка                                                | Результат                                                                                     |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `npm run check`                                         | Успех в исходном Git-worktree: форматирование, ссылки, синтаксис лендинга и общая сборка      |
| `npm run check:web`                                     | Успех: 32 файла, 200 тестов, самостоятельные сборки врача и администратора                    |
| `npm run check:fixtures`                                | Успех: 4 файла, 61 тест; normal/empty/long соответствуют схеме                                |
| `npm run check:mobile`                                  | Успех: типы, lint, 84 теста                                                                   |
| `npm run build:doctor:api`                              | Успех: 0 ошибок, 0 предупреждений                                                             |
| `node scripts/verify-doctor-api-ci.mjs`                 | Успех: 38 сценариев на отдельной синтетической БД                                             |
| `DOCTOR_UI_MODE=demo node scripts/verify-doctor-ui.mjs` | Успех: 10 этапов, включая сохранение приёма, диалоги, клавиатуру, 360/390 px и reduced motion |

Проверки воспроизводили потерю соматических состояний в снимке и возможность подтверждения диагноза без специальности; после исправлений соответствующие регрессионные проверки проходят. API-сценарий отдельно сравнивает снимки клиента и сервера с выбранными соматическими состояниями и диагнозом.

Первый веб-прогон с копией зависимостей с другого пути был недостоверен из-за двух экземпляров React. После чистой установки на D: эта проблема отсутствует. Один последующий прогон остановился по 5-секундному таймауту ExampleWorkbench при параллельной нагрузке; полный повтор прошёл без изменения таймаутов и теста.

Дополнительный браузерный сценарий прошёл: поиск кода и выбор с клавиатуры, явный статус диагноза, сохранение после перезагрузки, пустая выдача и ширина 390 px без горизонтального переполнения.

## Границы проверки и поставки

Это синтетический демонстрационный контур, не клиническая апробация. МКБ-10 содержит 17 учебных значений и не является полной утверждённой выгрузкой НСИ. Предупреждения npm audit и размерных chunk сборки администратора не устранялись изменением зависимостей.

Старые серверные карты новой схемой не обслуживаются без отдельно согласованной миграции. [Требования к отдельному стенду и откату](../doctor-workspace-runbook.md#совместимость-модели-контекста-и-диагнозов-pr-35). Независимый approve человека и ревью общего контракта обязательны; самопроверка ИИ их не заменяет.
