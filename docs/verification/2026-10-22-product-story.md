# Проверка продуктового рассказа — 22 октября 2026

Утверждённый слоган — «Больше внимания человеку.». Он заменяет прежнюю подпись в подвале и закреплён в продуктовой концепции и инструкции сайта.

## Изменения

- Конкретное описание экосистемы рядом с устройствами и пассивная плашка мобильного приложения.
- «Наш подход»: четыре преимущества и явно демонстрационные результаты опроса с условной выборкой 80 человек. 64/80 = 80%, 56/80 = 70%, 60/80 = 75%. Реальных результатов опроса эти числа не представляют.
- Научные источники и сравнение собраны в раскрываемую часть подхода, прежние якоря сохранены.
- «Продукт» организован по ролям врача, пациента и клиники; добавлены иллюстрация аналитики и последовательность сопровождения. Клиническая карточка и полный интерактивный сценарий сохранены в разделе 02.
- Указаны статусы демо, мобильной разработки и планируемых механизмов. Финальная кнопка открывает демо врача.

## Результаты

- npm run check — успешно: форматирование, Markdown-ссылки, синтаксис и общая сборка.
- npm run check:web — успешно: типы, 42 теста в 9 файлах, сборки врача и администратора.
- git diff --check — успешно.
- Расширена существующая проверка интерактивного примера: вкладки продукта, скрытая ссылка пациента, переходы врача/клиники, клавиатурное переключение и раскрытие источников по якорям. Сохранён проход сценария пациента, врача и клиники.
- В браузере проверены ширины 320, 375, 768 и 1440 пикселей: горизонтального переполнения нет. Дублирующихся HTML id нет, карточка находится внутри раздела 02.
- Проверка свежим контекстом агентом важных дефектов не выявила; она не является независимым одобрением участника команды для PR.
