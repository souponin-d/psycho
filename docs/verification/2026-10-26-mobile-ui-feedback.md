# Android 0.4.3: проверка уточнений интерфейса

Основание — [issue #49](https://github.com/souponin-d/psycho/issues/49), [план](../superpowers/plans/2026-10-26-mobile-ui-feedback.md). Проверено 26 октября 2026 года на Android API 37, самостоятельная release-сборка, fontScale 1.0, без Metro. Только синтетический профиль. Владелец реализации — глава разработки.

## Изменения

1. Удалены «шаг за шагом» и абзац «Для зачёта дня нужны…» на экране «Мой план».
2. Текст «Принял» и «Пропустил» центрирован вертикально. На 0.4.2 нативная проверка обнаружила смещение 12 физических пикселей; на 0.4.3 отклонение не превышает 2 пикселей.
3. Вкладка называется «Лечение». Кнопка «Связаться с врачом» использует основной акцент текущей темы.
4. Кнопка обращения — «Отправить», подтверждение сервера — «Сообщение успешно отправлено!». Демо честно подтверждает локальное сохранение.
5. Края карты ощущений — «Грустно» и «Радость»; обновлены доступные подсказки. Смайлик и координатная модель сохранены.
6. Со второй страницы самоотчёта удалены все видимые упоминания обязательности, включая условную подсказку об обновлённом плане. Правила обязательного заполнения сохранены.
7. При повторном знакомстве на 0.4.2 воспроизведён пейзаж мира под рабочими страницами. Теперь он отображается только на первом и завершающем шагах. Все 13 шагов пройдены; на 11 рабочих страницах фон ровный. Самопроизвольное открытие отдельного экрана «Мой мир» не воспроизведено; исправление не заявляется решением неподтверждённой ошибки маршрутизации. Профиль, мир и клинические записи не сбрасываются.

## Проверки

Общая `npm run check` завершилась успешно: форматирование, Markdown-ссылки, синтаксис и объединённая сборка. Сборка предупреждает о крупных JS-чанках.

| Команда / сценарий                                                                   | Результат                                                                                    |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `npm run check:mobile`                                                               | TypeScript, ESLint; 146/146 тестов                                                           |
| `VITEST_MAX_WORKERS=1 npm run check:web`                                             | Контракты, формы, TypeScript, 349/349 тестов, обе web-сборки                                 |
| `npm run check:fixtures`                                                             | 61/61 тест; три набора соответствуют схеме                                                   |
| Android `:app:assembleRelease -PreactNativeArchitectures=arm64-v8a,x86_64 --offline` | Успешно, 0.4.3 / versionCode 7                                                               |
| `verify-ui-feedback-android.mjs --layout`                                            | Геометрия кнопок, названия, обращение, карта и отсутствие `обязат` на второй странице — PASS |
| `verify-ui-feedback-android.mjs --replay`                                            | 13 шагов, отсутствие отдельного экрана мира — PASS                                           |
| Действующий код → VPS → отправка синтетического обращения                            | Итоговый APK показал «Сообщение успешно отправлено!» после ответа сервера                    |

При статической проверке самоотчёта системная анимация временно отключалась, чтобы UIAutomator получил стабильное дерево; настройка восстановлена. Повторное знакомство проверено с обычной анимацией. Масштаб шрифта 1.0. Набор автопроверок клинического состояния и повторного знакомства входит в 146 mobile-тестов. Полная визуальная проверка всех тем и устройств не выполнялась.

API, база данных, права и клинические правила не менялись. На VPS добавлены только APK и контрольная сумма. Миграций нет; откат установкой предыдущего APK требует совместимого Android versionCode либо отдельной сборки отката, удалять данные приложения не требуется.
