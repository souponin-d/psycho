# Проверка клинической поддержки — 26.10.2026

Проверялся синтетический контур: два взрослых маршрута, варианты терапии, риски, нежелательные явления, маршрутизация и приверженность. Это техническая проверка правил по литературе, а не клиническое испытание.

## Выполненные проверки

- `npm run build:doctor:api`: сборка .NET 10 успешна.
- `VITEST_MAX_WORKERS=2 npm run check:web`: **319 тестов**, контракт, формы, TypeScript и сборки doctor/admin прошли. На Windows переменная задаётся через `$env:VITEST_MAX_WORKERS='2'`.
- `scripts/verify-doctor-api.mjs` на отдельной базе PostgreSQL: **83 сценария прошли**, включая сравнение TypeScript/C#, неизменность состояния при отказе, авторизацию, идемпотентность, устаревший источник, отдельное подтверждение проектов, блокировку препарата при сообщении об аллергии и защиту пациентской проекции. Тестовая SQL-база задаётся через `DOCTOR_API_TEST_DATABASE`; по умолчанию локальная `doctor_workspace`.
- Прямой вызов защит среды: **52 из 52** сочетаний команд и сред Production/Staging/отсутствующая/неверный регистр отклонены до изменения карты.
- `npm run check:fixtures`: **61 тест**, три набора примеров соответствуют схеме.
- `node scripts/verify-clinical-support-ui.mjs`: **4 браузерных сценария в каждом из двух режимов прошли**: локально с заблокированным API и через API/PostgreSQL с `CLINICAL_UI_MODE=server`. Проверены ГТР, депрессивные симптомы, проект плана, нежелательное явление и перезагрузка, узкий экран без переполнения и ошибок JavaScript.
- `DOCTOR_UI_MODE=all node scripts/verify-doctor-ui.mjs`: **28 шагов регрессии** — по 14 в локальном и серверном режиме, включая МКБ-10, ГРЛС, приём, шкалы, план, события и клавиатурную навигацию.
- `npm run check`: форматирование прошло; общий запуск остановился на **12 ранее существовавших битых ссылках** в локальных `artifacts/patient-main-pr.md` и `artifacts/v04-build/site/README.md`. Эти архивные файлы и правила проверки не изменялись. Следующие стадии выполнены отдельно: `npm run site:check` и `npm run build` прошли. Сборщик предупреждает о крупных JS-чанках.
- `git diff --check`: ошибок пробелов нет.

В регрессиях проверены: выбранное МНН при аллергии; сохранение нерассмотренной опасности после нового ответа; смена дня; повторное рассмотрение новой версии нежелательного явления с сохранением прежнего действия. Тяжесть и серьёзность события независимы. История назначения сохраняется после изменения расписания и отмены; отсутствие отметки не превращается в пропуск.

Проверки взаимодействий ограничены версионированным каталогом, а не всем множеством препаратов ГРЛС. Внешняя доставка, мобильная интеграция и просмотр инструкций не входят в этап. Прежние отчёты отражают состояние своих этапов; этот документ дополняет их.
