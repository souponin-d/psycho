# Переписка пациента и врача: промежуточная проверка

Это промежуточный отчёт по состоянию на 26 октября. Дальнейшие изменения и результаты проверок приводятся в [отчёте интеграции](2026-10-27-patient-doctor-integration.md).

Задача [#52](https://github.com/souponin-d/psycho/issues/52). Этап переписки и очереди; интеграция назначений, отметок приёма, самоотчётов и опросников этим не завершена. Проверено на синтетических данных 26 октября 2026 года.

В серверном режиме кнопка «Связаться с врачом» открывает согласованную историю переписки с полем отправки и кнопкой «Новое обращение». Демо использует прежнюю локальную форму. Подпись об автосохранении черновика убрана, само сохранение осталось. Сообщения, ожидающие ответа сервера, сохраняются на устройстве и видны как ожидающие отправки; повтор при активном подключении использует тот же идентификатор. Очереди разделяются по серверу, клинике, пациенту и учётной записи. После перезапуска требуется повторный вход по коду.

Канал также проверяет прочитанную серверную проекцию подтверждённых назначений, включая несколько препаратов; некорректная проекция не подменяется локальным планом и не блокирует переписку. Это пока подготовка: мобильный экран плана продолжает использовать локальные данные, а текстовое расписание врача не преобразуется в напоминания или отметки приёма.

## Фактические проверки

- `npm run check:mobile`: TypeScript, ESLint и 160 тестов — успешно.
- `node scripts/verify-patient-message-sync.mjs`: локальная синтетическая PostgreSQL и API; потеря ответа после сохранения, повтор без дубля в карточке врача, ответ врача доступен пациенту — успешно.
- Android release на эмуляторе API 37, fontScale 1.0: заголовок, история, поле, отправка на VPS и новая форма — проверены. При отключении Wi-Fi и мобильной сети сообщение отобразилось ожидающим и было подтверждено после восстановления связи; исходные настройки сети восстановлены. Введённые для проверки сообщения синтетические.
- `npm run check`: форматирование, ссылки, синтаксис и сборка — успешно до последних локальных правок; повторить перед сдачей всех этапов.
- `npm run check:fixtures`: 61 тест и проверка схем — успешно.

Реальная отправка сообщения не подтверждает прочтение врачом. API, сервер и БД на VPS не обновлялись; APK для проверки собирался локально.
