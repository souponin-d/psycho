Основной интерфейс подключён вместо прежней демонстрации; прежние компоненты и примеры сохранены. Учебный режим использует IndexedDB, серверный — API.

Извлечение структурированных строк: 2 теста, сначала один падал, после реализации оба проходят. Совместная проверка — 10 тестов, 2 файла, успешно; `npx tsc --noEmit` успешно.

Браузерная проверка `scratch/doctor-ui-smoke.mjs`: вход в учебный режим, карта, создание и начало приёма, жалобы, история, оценка безопасности, заключение, рекомендации, завершение, перезагрузка, динамика, ширина 390 px — успешно. Ошибок JS 0, горизонтального переполнения нет. Скриншоты пока в `.cache/doctor-screens/`; окончательные свидетельства будут сохранены после расширенного прохода.

Сервер: ASP.NET Core 10.0.13 / SDK 10.0.402, Npgsql 10.0.3, PostgreSQL 17.11. Cookie, CSRF, ограничение входа, принадлежность клинике и связь с пациентом, транзакционная история/аудит/идемпотентность. Отдельный ограниченный пациентский API поддерживает отчёт, сообщения и подтверждение получения. Исходный нормативный документ выдаётся по ID с проверкой SHA256 и сессии врача.

Интеграционный проход `scratch/doctor-api-integration.mjs`: 20 проверок на реальной PostgreSQL успешно — анонимный доступ, вход, CSRF, сохранение, конфликт, запрет неполного завершения, автор сервера, идемпотентность/повтор ключа с другим действием, неизменяемость/дополнение, отчёт и событие в одной транзакции, порядок обработки, чужой врач/клиника, запрет пациенту врачебных маршрутов/команд, поступление отчёта пациентского API врачу, выдача источника по хешу.

Выявленная интеграцией ошибка Npgsql с несколькими SQL-операторами и позиционными параметрами исправлена: изменение, версия и аудит выполняются одним выражением с CTE в транзакции. После исправления сборка: 0 предупреждений / 0 ошибок; весь интеграционный проход успешен.

Решения исполнителя:

- Автоматический worktree оказался вне разрешённой области записи; созданная копия отправлена в архив инструментом приложения. Работа продолжена в разрешённой папке на отдельной ветке. Изменённые ранее файлы не перезаписывались.
- Клинические пороги/дозировки/ключи с конфликтами не активированы. Врач регистрирует результат конкретной внешней формы и подтверждает собственное решение с источниками. Клиническая валидация остаётся отдельным обязательным условием.
- Извлечение документа на текущем этапе — точное выделение строк с заголовками и ручная проверка фрагмента; не выдаётся за универсальный NLP/OCR.
- Развёртывание для реальных данных и юридическая квалификация ПО не выполнялись. Локальная тестовая БД содержит только синтетические сведения.

Дополнительно выполнены расширенный браузерный проход в двух режимах, восстановление БД, генерация OpenAPI/клиента, инструкции запуска, обзоры и исправления доступности/конфликтов/автосохранения.
