# Проверка Синкли 0.4.0

Локальная task-ветка `codex/22-patient-v04`, issue #22. Веб- и клинические контракты не менялись; врачебная связь и назначения моделируются на синтетических данных.

## Что изменилось

- Пейзаж «Моего пути» занимает весь экран, включая область под заголовком. Сплошная цветная шапка убрана по последнему уточнению владельца. Интерактивные даты ограничены измеряемым окном между верхними и нижними элементами; фон прокручивается на UI thread.
- Фактурные точки дней содержат отметки обязательств и рост растения. Три дня на участке, семь дней в наградной главе. Своя расстановка остаётся на сохранённом участке, независимо от смены текущей даты.
- Все 20 предметов мира имеют собственную растровую фактуру. Четыре зарегистрированных дневных/ночных пейзажа сохраняют топологию.
- Шарф, худи и накидка имеют отдельные выкройки для облачка и пушистика. Маска глубины отделяет задние края от передней одежды; привязки рассчитываются для каждого исходного кадра. Исходные тела/лица не заменены генерациями. Лапки и место крепления аксессуара перекрывают ткань. Промпты и происхождение ресурсов сохранены в manifest JSON.
- Кадры спутников смешиваются двумя постоянными слоями вместо резкого переключения; фоновый экран и Reduce Motion останавливают проигрывание. Награда имеет статическое представление и сохранённое подтверждение показа.
- Полный самоотчёт разбит на понятные шаги; необязательный личный момент не заменяет его. Идентичный отчёт/черновик не создаёт новых ревизий/записей. Дата открытой формы фиксируется.
- Знакомство содержит 13 шагов, сохранение прогресса и отдельные учебные действия. Есть проба отметки приёма, карта ощущений, объяснение обязательств, вертикальная карта и перемещение предмета. Учебные действия не завершают терапевтические задания.
- Цель редактируется в настройках. Чат/черновик сохраняются локально, есть рабочие переходы и подтверждение очистки. Шаблоны не привязаны к местоположению мебели.
- Граничные стрелки календаря отключены; на 320 dp используются доступные строки. Графики имеют выбор даты/значения и текстовый эквивалент; отсутствие записи остаётся пробелом. Ревизии раскрывают все поля и фактическое время.
- Начало трудности выбирается явно, значимые ответы не предвыбраны, черновик обращения сохраняется. Время напоминаний выбирается часами/минутами или вводится вручную; показан ближайший фактически запланированный сигнал.

## Выполненная проверка

- `npm run check:mobile`: types, lint, 123/123 модульных и интеграционных проверок. Новые проверки прошли RED→GREEN для дедупликации приёма/черновика, обращений, очереди кадров, геометрии одежды, участков мира, отчёта, обучения, переписки, миграции наград и ревизий.
- `npm run check`, `npm run check:web`, `npm run check:fixtures`: пройдены. Web/fixtures: результаты в локальных журналах; предупреждение Vite о крупных существующих chunks не является ошибкой сборки.
- Независимое техническое ревью выявило цикл автосохранения, блокирование следующей реакции наградой и неиспользуемую маску глубины. Все три замечания исправлены; отдельно перепроверен Reduce Motion. Это техническое AI-ревью, не независимое одобрение участника для PR.
- Android: установка обновлением существующего пакета, реальный проход 13 шагов знакомства, гардеробы обоих видов, светлая/ночная сцены. Обход пути/плана/истории на 320, 366, 412 dp при font scale 1.0 и 1.3. Кадровое движение записано в настоящий MP4.
- Исходный комплект 0.3 и все изменения хранятся в task-ветке; прямого изменения `main` или публикации не выполнялось.

## Ограничения приёмки

- Это APK для проверки владельцем на телефоне. Эмулятор не подтверждает ощущение вибрации, политику батареи конкретного производителя и полный звуковой маршрут TalkBack. Проверку на физическом устройстве нельзя считать выполненной по скриншотам или build.
- Длинный путь виртуализирован; серия синтетических сценариев и сохранение 500 старых записей проверяются автоматически. Полноценный GPU/FPS-профиль на целевом физическом устройстве остаётся отдельной аппаратной приёмкой.
- Реального сервера врача и внешнего чат-API нет; полные русские формы сохранены без изменения клинических порогов. До подключения настоящих клинических процессов нужны предусмотренные репозиторием согласования.

Локальные доказательства находятся в `D:/Projects/Psycho/artifacts/`: `mobile-v04-worn`, `mobile-v04-acceptance`, `mobile-v04-sizes`, `mobile-v04-motion`, журналы `v04-*-check.log` и `v04-release-final-native.log`. Они не являются автоматически опубликованными материалами PR.
