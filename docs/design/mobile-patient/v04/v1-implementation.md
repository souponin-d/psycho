# Веха V1 — перенос оформления в Android

Статус: реализация для показа владельцу; оформление ещё не утверждено. Это промежуточный участок 0.4, не завершённый релиз.

## Неизменный эталон

Тела, лица и последовательности кадров из 0.3 не менялись. Макеты 0.4 служат ориентиром компоновки, а не заменой персонажей.

- `assets/companions/cloud-idle-0.png`: SHA256 `750aebeb5d5dbcfcb9953147c3bd78d8575432763f10c64387c1e51c18939379`.
- `assets/companions/fluffy-idle-0.png`: SHA256 `39b9eadb03d96ce54fc1bdb9396fbf54fff5798c5e966fe6917a7d93d1b2bc97`.
- `src/config/companionFrames.ts` и прежние PNG не изменены.

## Область пробы

1. Каменная отметка с датой и словесным статусом вместо плоского круга. Будущее не получает галочку.
2. Более компактный верх пути с остатком дел и датами текущей главы, одно основное действие внизу.
3. Самостоятельная текстурная ткань только для шарфа облачка. Прочая одежда и аксессуары ещё прежние; эта веха не означает готовность всего гардероба.

Два новых ресурса и точные запросы записаны в [v1-assets.json](v1-assets.json). Новые лица и тела не генерировались. Освещение спокойное, материал сравнивается с существующим берегом.

## Независимые исправления

- Повторное нажатие «Принял»/«Пропустил» в плане не меняет исходную отметку. Явное исправление в истории создаёт новую ревизию.
- Обращение требует собственного выбора выраженности и предпочтения связи; дата начала отделена от даты записи. Неоконченная форма сохраняется как черновик.

## Проверки

- `npm run check:mobile`: 95/95, TypeScript и ESLint без ошибок.
- `npm run check`: форматирование, ссылки Markdown, JavaScript и общий build прошли; Vite предупреждает о крупных чанках существующего web build.
- Release Android x86_64 собран и установлен обновлением поверх 0.3; профиль и выбранное облачко сохранились. Это внутренний кандидат V1 с прежним versionCode, не итоговый APK 0.4 для телефона.
- Реальные снимки 1080×2400 и 840×1680 (320 dp, font_scale 1.3); сегодняшняя дата и основное действие доступны. Мир прокручивается под фиксированными панелями: одновременная видимость спутника и дня на узком экране пока не гарантируется.
- Нативная запись реакции на касание: 10.66 с, 1080×2400, без монтажа; воспроизведение и кадр на второй секунде проверены в Chromium.
- Найден и устранён Android NPE в react-native-svg: вложенный Svg с Filter не имеет current bitmap. Ткань теперь находится в общем корневом Svg без вложенного фильтра; последующий запуск прошёл. Это ограничение учитывать при развитии гардероба.
- Маршрутизация учитывает размер тела и подписи камней, а не только точку положения; отдельный поведенческий тест воспроизвёл перекрытие и прошёл после исправления.
- Материалы локального показа: `D:/Projects/Psycho/artifacts/mobile-v04-v1/review.html`, три PNG и `native-motion.mp4`. Промежуточные сборки не публиковались.
- Для Windows понадобился короткий временный каталог сборки `D:/sv4`: исходный длинный worktree упирался в MAX_PATH, а диск C заполнился. Это копия текущих исходников для сборки, не другая ветка; новые зависимости не добавлены. Удалены только созданные этой проверкой Android build/.cxx внутри node_modules рабочего worktree; на C освобождено около 0.8 ГБ. Основной checkout и его изменения не затрагивались.

## Граница согласования

После просмотра реального Android владелец утверждает камни, плотность пути и материал ткани. До этого одежда остальных персонажей и прочие экраны не переводятся на предложенное оформление. Полная спецификация 0.4 и оставшиеся вехи сохраняются.
