# План: продуктовый рассказ Синкли

> Исполнение: последовательно в текущей рабочей ветке, без публикации.

**Цель:** реализовать утверждённое в чате предложение: описание экосистемы, наш подход с макетом опроса, продукт по ролям, ясные статусы и единый слоган.
**Архитектура:** существующие HTML/CSS/JavaScript лендинга, без новых зависимостей и изменений клинической логики.
**Основание:** утверждение пользователя от 22 октября 2026 года и слоган «Больше внимания человеку.».

## Шаги

- [x] Обновить описание, добавить неинтерактивную мобильную плашку, закрепить слоган в подвале и документации.
- [x] Собрать четыре преимущества и явно условный опрос (80 человек, 64/56/60 ответов) в двух колонках. Перенести клиническую карточку в раздел 02. Исследования сократить в раскрываемую часть подхода, сравнение оставить доступным по прежнему якорю.
- [x] Перестроить вкладки продукта на «Врачу / Пациенту / Клинике». Сохранить клавиатурную навигацию, показать статусы и аналитику клиники. Добавить цепочку сопровождения. Конечная кнопка ведёт в демо врача.
- [x] Проверить переключение ролей и переходы в существующем тесте; выполнить npm run check и npm run check:web; проверить браузер на широком и узком экранах, сохранить снимки.

## Ограничения и проверка

Сохраняем HERO, фотографии, устройства, интерактивный учебный сценарий, приватность и раздельные роли доступа. Данные опроса не выдаются за настоящие результаты. Планы не обозначаются готовой клинической системой. При 320/375/768/1440 px не должно быть горизонтального переполнения; вкладки доступны с клавиатуры. Новых тестов для статического текста не требуется. Коммиты, push и PR не входят в текущую локальную демонстрацию.

## Результат

Реализовано последовательно в текущей ветке. npm run check и npm run check:web прошли; 42 теста в 9 файлах. Проверка ролей сначала падала на отсутствующей вкладке «Пациенту», после реализации прошла. Проверены переходы к источникам и сравнению. В браузере нет переполнения при ширине 320, 375, 768 и 1440 пикселей. Дополнительное read-only ревью свежим контекстом важных дефектов не обнаружило. Изменения остаются локальными.
