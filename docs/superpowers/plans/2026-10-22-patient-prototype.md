# P04a: план реализации прототипа пациента

> **Статус документа:** Исторический план задачи. Поручения, целевые пути, чекбоксы и ограничения описывают исходную постановку, а не состояние текущего main. Сохранён для требований и прослеживаемости; не использовать как инструкцию запуска. [Текущее состояние](../../status.md).

**Goal:** Получить автономный APK по [описанию](../specs/2026-10-22-patient-prototype-design.md).

**Architecture:** Expo SDK 55 / React Native, Expo Router. Изолированные конфигурация, состояние и транспорт демонстрационного чата; локальные изображения и семантические темы. Сервер не требуется.

**Tech Stack:** React Native, Expo, TypeScript, Animated, SVG, AsyncStorage.

## Ограничения

Отдельная ветка; не затрагивать чужие `site/assets/team/`. Один корневой lockfile; точные зависимости; веб и fixtures проверяются без Android SDK. Локальная сборка разрешена владельцем. Публикация и слияние не входят в поручение.

## Review Focus

- Повреждённое хранилище: безопасные значения, без зависания на старте.
- Повторные нажатия/перезапуск: отметка задачи не дублируется, запись сохраняется.
- Смена темы и маскота: функции и история остаются теми же.
- Клавиатура/небольшой экран/уменьшение движения: действия доступны.
- Чат без сети: демонстрационный ответ, отсутствие ложного статуса реальной связи.
