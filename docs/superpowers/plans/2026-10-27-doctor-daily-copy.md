# Ежедневная работа врача: надписи и переходы

Основание — шесть согласованных правок владельца от 27 октября. Реализация подготовлена в отдельной ветке; по поручению владельца от 27 октября изменения поставляются через PR в `main`.

1. Переименовать действие изменения назначения.
2. В расписании вместо числового смещения показать часовой пояс с автоматической подстановкой устройства; сохранённое смещение не менять. Формат API остаётся прежним, с фиксированным UTC-смещением.
3. Убрать постоянные объяснения про черновики и техническое устройство. Сохранить ошибки, состояния, клинические ограничения и подтверждения действий.
4. Перенести технические идентификаторы, версии и развёрнутые основания в раскрытия. Значения в хранилище, аудит и правила не менять.
5. Убрать ссылки на законы из формы сообщений.
6. Ошибки завершения вести к соответствующему полю с фокусом; ошибки согласий — к форме с нужным видом согласия. Применить и в сводке, и в окне подтверждения. Проверки завершения не ослаблять.

Проверка: регрессионные тесты часового пояса и переходов к полям, существующие проверки веба/данных/сборки, локальный браузер. Никаких изменений клинических порогов, API или VPS.
