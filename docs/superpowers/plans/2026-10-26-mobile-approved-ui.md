# Согласованный интерфейс mobile и подготовка связи с сервером

> Исполнение: `superpowers:executing-plans`, последовательно. Источник — утверждённые пользователем макеты и уточнения от 26 октября. Issue для этого пакета ещё не создана; публикация/PR не входят в текущее поручение.

**Цель:** внедрить принятые правки Android, сохранив выбранные пользователем исключения, и подготовить проверяемую границу чтения существующего patient API.

**Архитектура:** существующие команды/SQLite/контракты сохраняются. Оформление не меняет медицинские расчёты и не объявляет локальное сохранение доставкой. Подготовленный read-only gateway не подключается к пользовательскому сценарию до согласования сессии, проекций, версий и адреса стенда.

**Стек:** текущие RN/Expo/TypeScript, Node 24; без новых зависимостей. Отдельный worktree/ветка `codex/mobile-approved-ui`; врачебные изменения основного checkout не переносятся.

## Принятые ограничения

- Сохранить текущий `ThemePicker` без изменений; заголовок настроек — «Настройки» вместо «Пусть будет по-вашему».
- `FeelingCharacter` не изменять. Исправить только начальную инструкцию карты.
- График сна сохранить; дополнить текстовым значением выбранной даты, а не заменять график списком.
- Сохранить «Войти в демо-режиме» и «Сейчас подключается учебный план на синтетических данных…». Остальные обозначения демо/учебного режима убрать из пользовательского отображения; реальные сообщения об ошибках/разрешениях сохраняются.
- Оригинальные PNG тел/лиц и цвета; удалить выбор окраски из обучения, мастерской и preview. Поля цвета прежних данных остаются совместимыми, но на изображение не влияют.
- Все последующие нативные проверки — font scale 1.0, исходное разрешение эмулятора; iOS исключён.
- Не менять сервер, shared contracts, генератор/сгенерированные клиенты, клинические ключи и содержимое опросников.

## Особое внимание

1. Смена реакции посреди перехода не оставляет оба слоя прозрачными; последний готовый кадр остаётся видимым при задержке нового.
2. Цветовые поля старого профиля не меняют исходные цвета, обновление сохраняет мир/историю/одежду.
3. Пропуски сна остаются пропусками; график и словесное значение доступны одновременно.
4. Удаление оговорок не превращает «Сохранено» в «Отправлено» и не добавляет ложную дозировку.
5. Неактивный gateway не делает запросов без явного вызова; HTTP только для явно разрешённого локального стенда, никакой автоподмены серверного плана учебным.
