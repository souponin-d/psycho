# Навигация пациента и отображение карты — план реализации

**Задача:** #57, владелец souponin-d. Пользователь поручил реализацию после обсуждения; дополнительное согласование макета не требуется.

**Результат:** четыре вкладки «Путь», «Лечение», «Врач», «Рядом». История открывается круглой кнопкой на плашке «Мой путь» и возвращает назад. Экран «Связь с врачом» содержит кнопку формы обращения и одну карточку переписки, сама переписка открывается отдельно. Настройки доступны из заголовков других разделов и существующего редактирования цели.

**Архитектура:** существующая Expo Router навигация и PatientConnectionProvider; никаких API/DB изменений. История переносится из tabs в защищённый корневой stack с сохранением URL `/history`. Новый таб `doctor` использует существующие `/contact` и `/doctor-chat`, показывает последнее сообщение и честный статус доступа. Демо не получает мнимую переписку врача. Onest, текущие темы и SVG-стиль сохраняются. Фон/объекты карты получают общий viewport и отступы прокрутки, камера учитывает панели.
