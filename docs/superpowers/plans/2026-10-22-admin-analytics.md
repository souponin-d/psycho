# Аналитическое демо администратора — план

> **For agentic workers:** Use superpowers:executing-plans. Выполнять последовательно; поручение пользователя уже разрешает реализацию.

**Goal:** Достоверное аналитическое демо с тремя ролями и сквозными локальными событиями для руководителя и жюри.

**Architecture:** Новый локальный analytics-модуль владеет событийным набором, проекциями, фильтрами и сеансом. Текущая оболочка переиспользуется и расширяется; presentation и отдельные приложения врача/пациента не меняются. Старые JSON проверяются прежней схемой и остаются совместимыми; публичное демо использует событийную проекцию.

**Tech Stack:** существующие React/TypeScript/Vite/Zod/CSS Modules/Vitest, SVG, CSV/print без новых пакетов.

**Spec:** [Дизайн и границы](../specs/2026-10-22-admin-analytics-design.md).

## Review Focus

1. Укороченный период/фильтр без наблюдений: знаменатель и сравнение не выдумываются.
2. Повторное действие/перезагрузка: событие считается один раз; повреждённое сохранение объясняется.
3. Смена врача/отделения: несовместимый фильтр сбрасывается, экспорт соответствует экрану.
4. Разные версии/неполные пары оценки: исключаются из парного сравнения, N виден.
5. Узкий экран/длинные подписи: нет переполнения и недостижимых действий; график имеет таблицу.
