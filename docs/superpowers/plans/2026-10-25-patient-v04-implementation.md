# Реализация Синкли 0.4 — план и визуальные контрольные точки

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Выполнять последовательно, без делегирования реализации. Пользователь требует согласовывать основные визуальные вехи до распространения решения.

**Goal:** исправить сценарии 0.3 и реализовать 0.4 с сохранением утверждённых персонажей и контролируемым переносом оформления.

**Architecture:** существующие core/repository/providers React Native + Expo остаются основой. Правила исправляются в чистом reducer/командах с поведенческими тестами; UI использует те же контракты. Визуальные изменения вводятся вертикальными участками и проверяются на Android перед расширением.

**Tech Stack:** React Native 0.83.10, Expo 55, TypeScript, SQLite, react-native-svg, существующий Animated native driver; новые runtime-зависимости не нужны для первой вехи.

**Spec:** [спецификация 0.4](../specs/2026-10-25-patient-v04-design.md).

## Глобальные ограничения

- Утверждённые тела/лица персонажей — существующие assets/companions/*.png из 0.3. Новые сгенерированные макеты не заменяют персонажей; одежда/предметы — отдельные слои.
- Естественный спокойный свет, один выбранный спутник, встроенная каменная отметка дня, вертикальный путь.
- Граница дня 00:00, обязательный отчёт/назначенный тест, сохранение наград/мира после пропуска; никаких реальных назначений/отправок/LLM API.
- Прежний пакет/ключ сохраняются. До конца поставки не объявлять APK полной 0.4.
- Основные визуальные вехи согласовываются с владельцем. В ожидании визуального решения допустимы независимые исправления данных; спорное оформление не переносится повсеместно.
- Чужие изменения основного checkout не затрагиваются; слияние только через PR/проверки/независимое одобрение.

## Особое внимание при проверке

1. Повтор «Принял» с новым временем не должен менять факт; явное исправление времени должно оставаться доступным.
2. Отсутствующие ответы/неверная дата обращения не превращаются в заранее выбранную лёгкую трудность.
3. Перезапуск/уход с формы не теряют черновик; старая база v2 остаётся читаемой.
4. Крупный шрифт и узкий экран не скрывают сегодняшнюю точку или действие за HUD.
5. Новый слой ткани и крайняя фаза движения не изменяют лицо/силуэт и не обрезаются.
