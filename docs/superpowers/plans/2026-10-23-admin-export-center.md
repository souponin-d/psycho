# Центр экспорта и новые визуальные направления

> **For agentic workers:** Использовать superpowers:executing-plans; пользователь поручил реализацию центра экспорта. Графики пока остаются предложениями.

**Goal:** Реальные PDF/XLSX/CSV/PNG из зафиксированной текущей выборки с выбором разделов, предпросмотром и повторным скачиванием.

**Architecture:** Чистая модель exportSnapshot фиксирует метаданные и типизированные таблицы. Ленивые writers создают файлы. ExportCenter управляет составом, состоянием формирования/ошибки/отмены и хранит до пяти готовых файлов в памяти до закрытия раздела. Reports становится центром экспорта; остальные графики и клинические расчёты не меняются.

**Tech Stack:** React/TypeScript; exceljs 4.4.0, pdf-lib 1.17.1, @pdf-lib/fontkit 1.1.1; canvas для PNG, локальный Onest для кириллицы.

**Spec:** одобренный пользователем вариант 8 — формат, состав и предпросмотр; PDF для показа, XLSX для анализа, CSV для таблицы, PNG для графика. Метаданные и методика обязательны. Пустая выборка объясняется. CSV выбирает одну таблицу явно, без смешивания разных схем. PNG сохраняет текущую динамику с заголовком, периодом и легендой.

## Global Constraints

- Три роли и серверные границы не меняются. Экспорт доступен в существующем пространстве руководителя.
- Только синтетические наборы, русский UI; медицинские пояснения и расчёты сохраняются.
- Графики приложения не заменяются. Девять новых эскизов: по три для инфографики, плотной аналитики и редакционного стиля.
- Исходный checkout D:/Projects/Psycho не изменять; работа в codex/p10-admin-analytics.

## Review Focus

1. Смена фильтра во время формирования: файл и история сохраняют исходный снимок.
2. Пропуски и нули не смешиваются, CSV-текст не становится формулой Excel.
3. Длинная кириллица, переносы и 180 дней: PDF читаем и корректно разбит на страницы.
4. Ошибка шрифта/генерации и отмена не создают ложного готового файла.
5. Повторное скачивание получает тот же Blob; очистка истории освобождает память.
