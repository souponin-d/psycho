# Кабинет врача после интеграции 0.4.4

Задача: [#55](https://github.com/souponin-d/psycho/issues/55). Владелец — souponin-d.

1. Начать ветку от актуального `main`, сохранив принятые PR №50–54.
2. Для дистанционного изменения существующего препарата разрешить ввод дозировки, обоснования и причины. Остальные параметры показывать заблокированными. При выборе дистанционного приёма восстановить неизменяемые параметры исходного назначения. Существующую проверку допустимости использовать до отправки; серверные правила не менять.
3. Группировать мобильные самоотчёты по версии формы и `entityId`. Актуальность определяется временем получения сервером, при равенстве — порядком записей. Прежние записи, отметки просмотра и опасные признаки сохраняются в раскрываемой истории. Отдельные самоотчёты не объединять.
4. Проверить поведение тестами и интерфейс в браузере; выполнить обязательные проверки.
5. На явно синтетической карте проверить обмен: назначения, расписание, отметки и исправления, самоотчёты и версии, выданные GAD-7/PHQ-9, переписку и повторы команд. Врач использует Layero, пациент — VPS. Не запускать локальные скрипты с очисткой/seed на публичном сервере. Зафиксировать отдельно программную проверку канала и действия в установленном APK.
6. Подготовить PR в `main` с результатами и снимками. Не обновлять VPS и не сливать PR в этой задаче.

Контракты, пороги, источники и активация клинических правил не меняются. Работа только на синтетике. Миграции не требуются.
