# Лендинг «Синкли»

Маркетинговый сайт в оформлении «Белый бордо». Согласованная версия объединяет описание продукта, опрос пациентов, научную основу, экосистему, технологии и российский контур, сравнение рынка, тарифы, команду, контакты и FAQ.

## Запуск и сборка

Из корня репозитория:

```sh
npm ci --ignore-scripts
npm run dev -- --port 8765
npm run check
npm run check:web
```

`npm run build` собирает весь сайт в корневой `dist/`: лендинг, кабинет врача `doctor/`, демо администратора `demo/admin/` и общие ресурсы. Публиковать нужно весь `dist/`. Ссылки относительные; локальные адреса прототипов в сборку не входят. Серверная часть кабинета врача запускается отдельно.

## Состав и поведение

- `index.html` содержит текст, ссылки на источники, агрегаты опроса и начальное состояние тарифов.
- `styles.css` содержит оформление, адаптивную сетку и анимации; альтернативные варианты дизайна не включены.
- `app.js` управляет меню, переходами к началу секций с сохранением внутренних отступов, сменой экранов экосистемы при прокрутке, мозаиками и вкладками «Для клиники» / «Для инвестора».
- `monetization.js` сохраняет модель тарифов и расчёты TAM/SAM/SOM из предыдущей версии. На вкладке инвестора заголовок меняется на «Монетизация», описание подписки скрывается.
- `assets/product/` содержит мокап с пушистиком и экраны приложений на демонстрационных данных. PNG переведены в WebP без потери пикселей; экраны врача переключаются через URL ресурсов, обрабатываемые Vite.

Модальных окон продукта нет: врач и администратор открывают существующие демо, ссылка пациента переводит к встроенному экрану. Подложка, счётчик и прогресс-бар у мокапов экосистемы удалены. Контакты находятся в блоке пилотного внедрения. `prefers-reduced-motion` отключает необязательную анимацию; вкладки доступны с клавиатуры.

## Опрос и финансовая модель

В каждой мозаике 107 клеток. Закрашены 46, 39 и 31 клетка — 43%, 36% и 29% соответственно. Группы пересекаются; последнее значение объединяет ответы о непонимании цели опросов и недоверии к использованию ответов без повторного счёта. В репозитории остаются только агрегаты, без исходных анкет и свободных ответов.

Тарифы, численность специалистов и финансовые формулы сохранены. Доля 40% для SAM — сценарное допущение; SOM — цель к концу третьего года, а не фактическая выручка. Формулы и ссылки на данные раскрываются на вкладке инвестора.

## Проверка изменений

Тесты `scripts/site-landing-interactions.test.ts` и `scripts/site-monetization.test.ts` проверяют навигацию, клавиатуру, экраны, агрегаты опроса, переключение тарифов и финансовые расчёты. Перед PR дополнительно проверяется собранный сайт на компьютере и телефоне, включая обе вкладки и переходы к демо.
