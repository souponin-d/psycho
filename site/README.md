# Лендинг «Синкли»

Рекламный сайт концепции клинической экосистемы. HTML/CSS/SVG и браузерный JavaScript; Vite запускает сайт и собирает его вместе с веб-приложением врача и демонстрацией администратора. Сервер врача запускается отдельно.

Из корня репозитория:

```sh
npm ci --ignore-scripts
npm run dev -- --port 8765
```

Открой адрес, напечатанный Vite. Для проверенной конфигурации это `http://127.0.0.1:8765/`. Порт по умолчанию 5173 на текущем Windows-хосте недоступен; можно выбрать другой свободный порт.

```sh
npm run check
npm run build
npm run preview -- --port 8766
```

Готовые статические файлы находятся в `dist/` в корне: лендинг, `doctor/index.html`, `demo/admin/index.html` и общие ресурсы `assets/`. Публиковать нужно весь каталог с сохранением структуры. Ссылки и ресурсы относительные; домен и локальные порты в них не зашиты. Хостинг должен отдавать index.html вложенных каталогов и направлять `/api` на сервер врача для рабочего режима. Публикация не выполняется этой командой автоматически.

## Открыть веб-приложение врача

В шапке нажми «Войти врачу» или выбери «Открыть приложение врача» под HERO. Адрес `doctor/` загружает рабочее место врача с входом в клинику и учебным режимом на синтетических данных. Прежний вход `demo/doctor/` не собирается. Демо администратора остаётся по адресу `demo/admin/`.

Для лендинга, учебного режима врача и демо администратора достаточно `npm run dev`; отдельный веб-сервер на 8768 не требуется. Для входа в клинику нужен сервер из [инструкции рабочего места врача](../docs/doctor-workspace-runbook.md): локальный Vite проксирует `/api` на `127.0.0.1:5080`, а опубликованный сайт требует аналогичной маршрутизации. Команды `dev:doctor`, `dev:admin` и `dev:examples` сохранены для самостоятельной работы над компонентами.

В учебном режиме врача можно создавать карты и приёмы, вести наблюдение и оценивать динамику на вымышленных данных. Демо администратора показывает аналитику, три рабочие роли и центр экспорта. [Маршрут показа админки](../docs/verification/2026-10-22-admin-analytics.md), [исходные наборы](../docs/verification/2026-10-20-demo-style-data.md).

Заготовки задач #5–#7 доступны в отдельной сборке приложения врача по `#/examples`; с лендинга открывается рабочее место. Рабочий режим использует серверную авторизацию и хранение, учебный режим сохраняет синтетические данные в браузере. [Мобильный Android-прототип](../apps/mobile-patient/README.md) запускается отдельно.

Вне экрана и в скрытой вкладке кадры останавливаются. Компьютер, телефон и входы в демо сохранены ниже; прежний заголовок над ними удалён.

В блоке сразу под HERO описание и две кнопки демо размещены слева, компьютер и телефон — справа. На узких экранах композиция складывается в одну колонку. Клиническая карточка, учебный сценарий и четыре шага сопровождения удалены с лендинга. В «02 / Экосистема» оставлены три вкладки ролей и переходы в демо.

Шапка закреплена сверху при прокрутке. Пункты «Наш подход», «Продукт», «Отзывы», «Команда» ведут к соответствующим разделам. Раздел «Отзывы» содержит три явно обозначенные заглушки; это не отзывы реальных пользователей. Заголовок FAQ — «Вопросы» и «и ответы» с новой строки.

Файлы `site/assets/team/1.jpg`–`5.jpg` соответствуют порядку слева направо: Ксения Резвова, Елизавета Федорцова, Дарья Мисник, Елизавета Лихачева, Дмитрий Супонин. На узком экране порядок сохраняется сверху вниз. Подписи находятся в `site/index.html`.

1. Переключить вкладки «Врачу», «Пациенту», «Клинике».
2. Открыть веб-демо врача и администратора по соответствующим ссылкам.

## Позиционирование и слоган

Утверждённый слоган Синкли: **«Больше внимания человеку.»** Его используем в HERO и подвале; прежние «Клиническая поддержка. Человеческая связь.» и «Полная картина. Ближе к пациенту.» не являются действующими слоганами.

Синкли — цифровая экосистема для сопровождения пациентов с тревожной и депрессивной симптоматикой: рабочее пространство врача, приложение пациента и аналитика клиники.

Раздел «01 / Наш подход» объединяет преимущества и макет результатов опроса. Все числа условные (64/80, 56/80, 60/80); они не являются результатами реального исследования. После получения ответов заменить числа, вопросы, основания процентов, состав и объём выборки. Сравнение платформ показано открыто в продолжении «Нашего подхода». Научная основа вынесена в отдельный открытый раздел непосредственно перед защищённой архитектурой. Прежние якоря сохранены.

Раздел «02 / Экосистема» показывает роли «Врачу / Пациенту / Клинике», краткое описание пользы и экран соответствующей роли. Ссылки врача и клиники ведут в соответствующие веб-демо. У пациента показан макет; плашка мобильного приложения под входами в демо не интерактивна. Статусы отделяют демо, разработку мобильного приложения и планируемые возможности.

### Навигация и графики опроса

Отступ якорей равен измеренной высоте закреплённой шапки (ResizeObserver и обработчик изменения размера). Переходы верхнего меню совмещают верхнюю границу раздела с нижней границей шапки.

Опрос представлен каруселью «Кольца / Полосы / Мозаика». Во всех видах используются те же условные ответы 64/80, 56/80 и 60/80. Доступны стрелки, вкладки и клавиатура; автоматического переключения нет. Мозаика содержит по 80 ячеек на вопрос. Анимация появления отключается при prefers-reduced-motion. Без JavaScript остаются текстовые значения.

В футере используются «© 2026 · «Синкли»» и слоган. Общая подпись о демонстрационной версии удалена по решению пользователя; локальные обозначения макетов и вымышленных данных в соответствующих блоках сохранены.

Пометки вымышленных результатов опроса и заглушек отзывов сохранены. Верхняя строка футера с повторным логотипом, слоганом и ссылками удалена; нижняя строка copyright остаётся. ### Выравнивание вкладок экосистемы

Полоса платформ под устройствами удалена. Верхний отступ «Нашего подхода» уменьшен вдвое: 56/40/32.5 px для соответствующих размеров экрана. Раздел 02 называется «Экосистема». Вкладки имеют общую высоту, верх текста совпадает с верхом внутреннего изображения; под описанием находится основная кнопка демо. У пациента кнопка отключена, поскольку мобильного демо пока нет. Индикатор вкладок плавно перемещается; содержимое появляется с коротким сдвигом и прозрачностью, reduced-motion отключает движение. Подпись «Границы доказательств» удалена.

Корректировка высоты: общая высота вкладок опирается на компактные экраны врача и пациента, а не на более длинное описание клиники. Аналитическая сводка клиники и её текст сокращены под этот размер. Кнопка находится после описания с коротким отступом, без растягивания пустого пространства.

Порядок разделов: исследование аудитории с опросом → научная основа → экосистема → технологии и российский контур → рынок → монетизация → отзывы → команда → FAQ. В исследовательском блоке принят вариант «Компактные колонки»: заголовок «Что важно пациенту», согласованное описание под ним и три мозаики. На телефоне карточки располагаются вертикально, число и описание стоят рядом; мозаики становятся шире и ниже. Переключатель видов графика и прежние условные показатели удалены.

Агрегаты опроса из `anon_data.xlsx`: 107 анкет за 22–24 октября 2026 года; нет сил или желания — 46 (43%), забывчивость — 39 (36%), непонятна цель опросов или нет доверия к использованию ответов — 31 (29%). Последняя группа — объединение двух ответов без повторного счёта. Одна клетка соответствует одной анкете: в каждой мозаике 107 клеток, закрашены соответственно 46, 39 и 31. Группы пересекаются, проценты округлены до целого; результаты относятся к участникам опроса. Формулировки болей — краткое обобщение ответов, а не дословные цитаты. В репозитории сохранены только эти агрегаты, без исходных анкет и свободных ответов.

Тезис о вовлечённости пациента не означает, что результат лечения зависит только от него. Основание для редакционной формулировки — международное руководство [NICE NG222, разделы 1.4 и 1.9](https://www.nice.org.uk/guidance/ng222/chapter/Recommendations): участие в лечении, барьеры и соблюдение согласованного плана рассматриваются наряду с другими факторами. Это не клиническое правило Синкли и не подтверждение эффективности продукта.

Заключительный промоблок «Быть на связи. Видеть целиком.» удалён. После FAQ расположен компактный футер.

Подписи с датой и размером выборки, легенда клетки и примечание под мозаиками убраны из интерфейса; основания расчётов сохранены в этом документе. Мозаики заполняются один раз при появлении каждой карточки на экране: 200 мс на клетку, последовательная задержка 28 мс. Самая длинная последовательность занимает около 1,5 с. При уменьшении движения и без JavaScript сразу отображаются итоговые значения.

### Научная основа подхода

Раздел `#evidence` содержит четыре карточки в сетке 2 × 2 с пояснениями, ограничениями и ссылками на Краснова (2023), Боброва (2024), Мосолова (2026) и Husain (2025). Порядок: трудности описания состояния → сохранение участия в наблюдении → электронный дневник → регулярная оценка с коррекцией лечения. На телефоне карточки идут в одну колонку. Вступление описывает проведённый анализ научной литературы и фокус на задачах пациентов и врачей. Описание опроса размещено справа от заголовка «Что важно пациенту», на телефоне — под ним.

Ограничения сохранены непосредственно в разделе: отсев из исследования не равен прекращению лечения; исследование мониторинга относится к конкретной системе при БАР; эффект опросников для описания эмоций в работе Краснова не проверялся; различие в доле ремиссий к 24-й неделе у Husain не было статистически значимым. Исследования обосновывают подход, а клиническая эффективность Синкли не установлена. [Отчёт и источники](../docs/verification/2026-10-24-scientific-basis.md). Согласование редакционного текста пользователем не заменяет клиническую валидацию.

По решению пользователя из интерфейса удалены заключительная подпись о будущем клиническом исследовании и подпись о целевой архитектуре под вариантами размещения. Их удаление не подтверждает клиническую эффективность или готовность внедрения; ограничения продолжают действовать.
