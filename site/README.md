# Лендинг «Синкли»

Рекламный сайт концепции клинической экосистемы. HTML/CSS/SVG и браузерный JavaScript; Vite используется только для запуска и сборки. Клинические приложения и сервер отсутствуют.

Из корня репозитория:

```sh
npm ci --ignore-scripts
npm run dev -- --port 8765
```

Открой адрес, напечатанный Vite. Для проверенной конфигурации это `http://127.0.0.1:8765/`. Порт по умолчанию 5173 на текущем Windows-хосте недоступен; можно выбрать другой свободный порт.

```sh
npm run check
npm run build
npm run preview -- --port 8766
```

Готовые статические файлы находятся в `dist/` в корне. Публикация не выполняется автоматически. Перед публичным размещением проверь хостинг, access-логи и документацию оператора.

## Что можно попробовать

1. Переключить вкладки «Динамика», «Безопасность», «План лечения».
2. Переключить веб-, десктопный и мобильный мокапы.
3. Открыть демо, выбрать роль пациента и поделиться вымышленным самоотчётом.
4. Перейти к врачу, показать учебный сигнал, подтвердить учебное рассмотрение.
5. Перейти к клинике и увидеть ту же историю действий.
6. Проверить три клинических сценария и сброс демонстрации.
7. Открыть раздел о данных и FAQ, перейти к статьям и первичным страницам конкурентов.

Роли здесь — представления в одной демонстрации, а не реализованная авторизация. Состояние хранится только в памяти вкладки. Нет форм свободного ввода, загрузки медицинских файлов, cookies, аналитики, внешних шрифтовых сервисов или запросов с данными пациента. Полные тексты психометрических анкет не воспроизводятся.

## Ресурсы

Шрифт [Onest](https://github.com/google/fonts/tree/main/ofl/onest) хранится локально; [лицензия OFL](assets/fonts/OFL.txt) прилагается и копируется в сборку как `dist/Onest-OFL.txt`. Иконки, знак и мокапы выполнены в коде.
