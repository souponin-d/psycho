# Визуальные ассеты Синкли

Это единая папка визуальных исходников приложения. Текущая версия **0.4.5** использует ресурсы семейства 0.4 из этого дерева; изображения доступны офлайн в APK. Исходники и референсы, которые не нужны во время работы приложения, хранятся отдельно внутри [sources/v04](sources/v04/README.md).

| Папка                    | Содержимое                                                                           |
| ------------------------ | ------------------------------------------------------------------------------------ |
| `images/`                | Пейзажи, светлые/ночные варианты, камень дня, исходные статические спутники          |
| `companions/`            | 24 зарегистрированных кадра обоих исходных персонажей и материалы аксессуаров        |
| `companions/worn-v04/`   | Шесть выкроек: шарф, худи, накидка отдельно для пушистика и облачка                  |
| `companions/fitted-v04/` | Примерки, по которым подготовлены выкройки; тела из них не используются в приложении |
| `world/v04/`             | 20 отдельных предметов мира с прозрачностью                                          |
| `fonts/`                 | Onest и лицензия OFL                                                                 |
| `sources/v04/`           | Полные листы анимации, макеты-референсы, промпты и происхождение изображений         |

[Машиночитаемый каталог](catalog-v04.json) содержит каждый файл, размер, SHA256, размеры PNG и ссылки из кода. `runtime` — реальные импорты Metro/app.json; `source` — архив исходников; `retained-reference` — сохранённые материалы, не импортируемые текущей версией. Один и тот же оригинал не дублируется, если финальный PNG байт-в-байт совпадает с генерацией: provenance указывает прямо на этот файл.

Проверка полноты и целостности:

```sh
node apps/mobile-patient/scripts/catalog-assets.mjs
```

После осознанного изменения ресурсов или ссылок из кода обновите каталог и повторите проверку:

```sh
node apps/mobile-patient/scripts/catalog-assets.mjs --write
node apps/mobile-patient/scripts/catalog-assets.mjs
```

Одежда привязывается к кадрам в `src/core/garmentRig.ts`, источники регистрируются в `src/config/wornAssets.ts`, слои рисуются в `src/components/Companion.tsx`. Исходная геометрия кадров — `src/config/companionGeometry.ts`. Эти файлы являются частью визуальных исходников, хотя находятся в коде: их не следует заменять неподвижной картинкой персонажа с одеждой.

Карта ощущений, мимика, иконки и управляющие поверхности редактируются в компонентах `FeelingCharacter`, `FeelingGrid`, `FeelingBackdrop`, `Icon`, `UI`, `JourneyDayMarker`; они созданы кодом и не имеют отдельного сгенерированного PNG.

Прежние промпты сохранены в [image-prompts.json](image-prompts.json); подробности кадров — в [companions/README.md](companions/README.md). Рабочие экраны и фактическая запись движения версии 0.4 находятся в [комплекте проверки](../../../docs/design/mobile-patient/v04/verification.md).
