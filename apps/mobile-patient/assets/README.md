# Локальные ассеты прототипа

Изображения созданы встроенным imagegen 22 октября 2026 по утверждённым пользователем направлениям. `fluffy.png` и `cloud.png` имеют прозрачный фон; `terrain-light.png` и `terrain-dark.png` — самостоятельные иллюстрации, не скриншоты интерфейса. Промпты сохранены в `image-prompts.json`.

Шрифт Onest переиспользован из сайта; лицензия OFL находится в `fonts/OFL.txt`. Все ресурсы включаются в APK и доступны без сети.
