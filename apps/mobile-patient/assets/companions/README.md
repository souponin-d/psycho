# Кадры и анимация спутников

В папке 24 локальных PNG: по четыре кадра ожидания, прогулки и эмоций для пушистика и облачка. Размер кадра 512×512; исходная ячейка сохранена целиком, масштабирована и зарегистрирована по центру тела/линии ног. Добавлены прозрачные поля минимум 32 px. `manifest.json` содержит границы видимой области и SHA256 исходных генераций.

PNG подготовлены из согласованного направления ImageGen. Воспроизведение не зависит от сети. Для замены позы достаточно заменить соответствующий файл, сохранив размер и регистрацию; после правки требуется повторная проверка границ.

- Состояния и траектории: `src/core/companion.ts`.
- Последовательности кадров: `src/config/companionAnimations.ts`.
- Статические ссылки для Metro: `src/config/companionFrames.ts`.
- Одежда/аксессуары и цветовая матрица: `src/components/Companion.tsx`.
- Пространственное движение и предметные реакции: `src/components/WorldCompanion.tsx`.
- Проверка крайних фаз со слоями одежды: `tests/companionState.test.ts`.

Одежда и аксессуары — отдельные SVG-слои, одинаково привязанные к каждой зарегистрированной позе. Изменение окраски выполняется нативной цветовой матрицей, сохраняя фактуру. Последняя строка матрицы убирает почти прозрачные шумовые пиксели источника, без отсечения видимого меха.

Не использовать старые тесные 6×4 атласы из исследовательских макетов: их поля не подходят для безопасного нативного воспроизведения.
