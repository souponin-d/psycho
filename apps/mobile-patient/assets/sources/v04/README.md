# Исходники и референсы 0.4

Эта папка дополняет основное дерево `assets`, а не заменяет его. Полный индекс всех визуальных файлов версии — [catalog-v04.json](../../catalog-v04.json).

- `animation-sheets/`: шесть полных исходных генераций (по одному листу на вид и группу idle/walk/emotion). Их SHA256 совпадают с sourceSha256 существующего манифеста кадров. Нужны для повторной нарезки и подготовки новых кадров.
- `design-reference/`: десять листов макетов, использовавшихся при разработке 0.4. Это художественные референсы; фактический интерфейс и последние правки владельца имеют приоритет над ранним макетом.
- `generation/`: исходные промпты и записи происхождения предметов, пейзажей, примерок, выкроек и первой визуальной вехи.
- [provenance.json](provenance.json): локальные пути от корня `assets` к оригиналам, контрольные суммы, соответствие исходных листов готовым кадрам.

Оригиналы генераций, уже сохранённые без изменения в `images`, `world` и `companions`, повторно не копируются. Все указанные локальные пути находятся внутри репозитория; файлы из временной папки Codex для их открытия не требуются. Исторические абсолютные пути в копиях generation-записей сохранены как метаданные происхождения; актуальные переносимые пути содержатся в provenance.

Тела и лица персонажей из примерок не подменяют утверждённые 24 кадра. В рабочем приложении используется один выбранный спутник. Кадры листов, выкройки и код регистрации нужно менять согласованно.
