# Мобильный прототип пациента Синкли

React Native + Expo SDK 55, TypeScript и Expo Router. Общий код Android/iOS. Это редактируемый интерфейс на синтетических данных: сервер, клинические правила, реальные назначения, настоящий AI и доставка врачу отсутствуют.

## Запуск

Из корня репозитория с Node.js 24:

```sh
npm ci --ignore-scripts
npm run dev:mobile
npm run check:mobile
```

Для нативного запуска нужен Android SDK 36, Build Tools 36.0.0, NDK 27.1.12297006 и JDK 17. Android Studio и имеющийся эмулятор подходят. Команда `npm run android --workspace @psycho/mobile-patient` создаёт development build. Для iOS нужны macOS/Xcode; сборка iOS в этом этапе не проверена.

## Автономный APK на Windows

Из корня:

```powershell
npm run prebuild:android --workspace @psycho/mobile-patient
Set-Location apps/mobile-patient/android
$env:NODE_ENV = 'production'
.\gradlew.bat assembleRelease '-PreactNativeArchitectures=arm64-v8a,x86_64' --max-workers=2 --console=plain
```

Результат: `apps/mobile-patient/android/app/build/outputs/apk/release/app-release.apk`. Сборка содержит JS, шрифт и изображения; Metro и интернет для работы не нужны. Используется локальная тестовая подпись Expo, не производственная подпись для магазина. Для установки: `adb install -r <путь-к-apk>` либо открыть APK на телефоне и разрешить установку из выбранного источника.

Не запускать `npm ci` одновременно с Gradle: Gradle удерживает файлы внутри `node_modules`. Перед чистой установкой остановить его через `gradlew.bat --stop`. Сгенерированные `android/` и `ios/` не коммитятся и не редактируются вручную; конфигурация находится в `app.json`.

## Что редактировать

| Область                                 | Файлы                                      |
| --------------------------------------- | ------------------------------------------ |
| Тексты онбординга, задачи, подписи      | `src/config/content.ts`                    |
| Цвета трёх тем, интервалы motion        | `src/theme/themes.ts`                      |
| Изображения, шрифт                      | `assets/images/`, `assets/fonts/`          |
| Движения и реакции спутника             | `src/components/Mascot.tsx`                |
| Рельеф и маршрут главного экрана        | `src/components/DayLandscape.tsx`          |
| Состояние и проверка сохранённых данных | `src/core/model.ts`, `src/core/storage.ts` |
| Замена демонстрационного чата           | `src/core/chat.ts`                         |
| Экраны и навигация                      | `src/app/`                                 |

Маскоты — прозрачные растровые изображения с нативными дыханием, покачиванием и реакцией на касание. Это анимация слоя, а не покадровая мимика или скелетная анимация; компонент можно заменить подготовленными анимациями. Настройка уменьшения движения учитывает систему и переключатель пользователя.

Тема, маскот, имя, время утра, выполнение плана и самоотчёты сохраняются в AsyncStorage. Хранилище предназначено только для демонстрационных сведений, не для настоящих медицинских данных. История доступна и за пределами последней недели. Повторное знакомство сохраняет историю; отдельный сброс после подтверждения удаляет локальные данные.

Чат отвечает локально по демонстрационным шаблонам. Сообщения живут только в открытой сессии. Настоящее API следует подключать через собственный серверный прокси с аутентификацией; ключ провайдера нельзя встраивать в приложение или `EXPO_PUBLIC_*`.

## Проверка

`npm run check:mobile` выполняет мобильный typecheck, ESLint и Node-тесты модели/сохранения/демо-чата без Android SDK. Веб-проверки изолированы от React Native и его версии React. Тесты охватывают ошибки чтения, последовательную запись, восстановление, повторные действия и старые даты истории. Эмуляторная проверка дополняет эти проверки; клинической апробацией она не является.

Документация использованных API: [Expo Router](https://docs.expo.dev/router/installation/), [Expo Font SDK 55](https://docs.expo.dev/versions/v55.0.0/sdk/font/), [локальные release-сборки](https://docs.expo.dev/build-reference/troubleshooting/).
